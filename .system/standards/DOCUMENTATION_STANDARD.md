## Purpose

Define the mandatory documentation format for all Creator AI Studio documents.

## Scope

This standard applies to all future controlled documentation in Creator AI Studio.

Required sections for every document:

- Document ID
- Title
- Version
- Status
- Author
- Created
- Last Updated
- Purpose
- Scope
- Dependencies
- Related Documents
- Change History

Official allowed statuses:

- Draft
- Review
- Approved
- Deprecated
- Archived

Official version format:

Major.Minor.Patch

Examples:

- 0.1.0
- 0.2.0
- 1.0.0
- 1.1.2

Official document naming convention:

- Use uppercase letters.
- Use underscores when word separation is required.
- Use the .md extension for Markdown documents.

Examples:

- VISION.md
- MISSION.md
- ROADMAP.md
- DOCUMENT_REGISTRY.md
