# Agent skills

This repository includes a curated set of reusable skills for agents and assistants.

## Included skills

- ui-ux-pro-max: UI/UX design intelligence with reusable design-system guidance
- ffmpeg: media conversion and processing helpers
- monorepo-management: monorepo workflow guidance
- supabase: Supabase integration guidance
- supabase-postgres-best-practices: database best practices
- vitest: testing guidance
